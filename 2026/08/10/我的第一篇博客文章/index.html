我的第一篇博客文章

建立博客的原因

现在是我大二升大三的暑假，在刚刚放暑假的一个月内，我尝试着去找实习，只是没想到实习这么难找，最后没有找到。我真的受不了了，为什么找个实习这么难，我不是去当廉价劳动力的吗？为什么这种吃力不讨好的事情都这么难啊。

在找实习碰壁后，我发现有一个自己的个人博客是一个加分的选项，于是我就开始简历自己的博客啦！不不不不不，还有一个重要的原因，那当然就是帅啦！哈哈哈。我在大二的时候看到有一个同龄人也建立了自己的博客，当时觉得老帅了，现在我也建立一个。还有，自己在生活中总有一些想法，我想把它们记录下来，但是一直苦于没有平台去给我记录，所以，由于种种原因，我的博客诞生了！

建立博客的过程

在我决定建立博客后，我就在bilibili上面去找教程了。经过一番了解后我使用了up主CodeSheep也就是程序羊的教程，全篇没有什么问题，讲得很直接，我基本一步到位就好了，有一些小问题，比如域名过期的问题就问了豆包，豆包很容易的就帮我解决了。说到这里我不得不谈一下豆包了。豆包其实两年前我还是很瞧不起他的，因为我好多作业给他写都是错一大推，气死我了这个傻包。但是最近这几个月，我觉得豆包也没那么差了，其实一些计算机相关的知识问一下都是可以解决的，但是就是答题方面太拉了吧。。。。。。亏你豆包还是国产AI题都不会做，真是丢尽了中国人的脸。言归正传，之后呢我就使用hexo搭建了我的个人博客了。这个视频很老，大概是18年左右的视频，他推荐了一个叫yilia的主题，然后讲解了一些基础的操作，自此，我的系统教程就看完了，然后就是自己摸索了。

自己对博客的探索

我觉得程序羊给的主题不好看，于是我在网上找了自己心仪的主题，在筛选下，我选择了fluid作为我的博客主题。在更换的时候我是用vs code + Claude更换的，我自己不会这些复杂的具体操作，只能求助AI啦，甚至我连了解fluid都是AI告诉我的，我连他有什么板块都不知道，只能走一步看一步了。在部署的时候，部署方式从HTTPS改为SSH，我也不知道有什么影响，看网上说好像问题不大。

在问Ai的过程中我也学了几招，比如说我要新建文章，就在_post/文件夹上右键后新建文件，然后取名为xxx.md就可以编辑了。编辑文章中按 Cmd + Shift + V 可以实现预览文章，写好后按 Cmd + S 保存，部署的话我就直接交给AI了。
